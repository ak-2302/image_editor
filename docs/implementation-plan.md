# Image Editor 実装計画

## 1. 実装ルール

- 各ステップを独立した作業単位として実施する
- 1ステップごとにコードを変更する
- 変更直後に、そのステップ専用のテストを実行する
- テストに失敗した場合は、次のステップへ進まない
- 各ステップで `npm run lint`、`npm run build`、ブラウザ操作、コンソールエラー、既存機能への影響を確認する
- 各ステップ完了時に日本語の`[AI]`付きコミットを作成する

## 2. 実装ステップ

### Step 1：現状の整理とデータモデル設計

#### 作業内容

`App.tsx`に分散している状態をプロジェクト単位のデータ構造へ整理する。

```ts
type Project = {
  version: number;
  name: string;
  canvas: {
    width: number;
    height: number;
    frameOpacity: number;
    frameThickness: number;
  };
  objects: EditorObject[];
};

type EditorObject = {
  id: string;
  type: "image" | "rectangle" | "circle" | "triangle" | "text";
  name: string;
  visible: boolean;
  transform: {
    x: number;
    y: number;
    scale: number;
    rotation: number;
    opacity: number;
  };
  effects: EffectInstance[];
  image?: { dataUrl: string; fileName: string };
  shape?: { fill: string };
  text?: {
    content: string;
    fontSize: number;
    color: string;
    bold: boolean;
    italic: boolean;
  };
};
```

#### 変更対象

- `src/features/layers/objectTypes.ts`
- `src/features/effects/effectDefinitions.ts`
- `src/features/project/projectTypes.ts`（新規）
- `src/App.tsx`

#### 完了条件

- 画像・図形・テキストを同一のオブジェクト型で扱える
- 各オブジェクトが独自の変形値とエフェクトを持つ
- オブジェクトIDを一意に管理できる
- 既存の画像・図形表示が壊れない

#### テスト要件

- TypeScriptの型エラーがない
- 既存画像が表示される
- 既存図形が表示される
- オブジェクト切り替えで既存の値が変わらない
- `npm run lint` 成功
- `npm run build` 成功

### Step 2：プロジェクト状態管理の分離

#### 作業内容

選択中オブジェクト、レイヤー一覧、オブジェクト名、表示状態、エフェクト、キャンバスサイズ、枠線設定をプロジェクト状態から管理する。

以下の操作関数を用意する。

- `addObject`
- `updateObject`
- `removeObject`
- `selectObject`
- `reorderObjects`
- `updateTransform`
- `updateEffect`
- `updateCanvas`

#### 完了条件

- オブジェクトの値が別オブジェクトと共有されない
- 選択対象の値が右側UIへ表示される
- 追加、削除、表示切り替えが動作する

#### テスト要件

- 画像を2個追加する
- 1個目のX座標を変更する
- 2個目を選択する
- 2個目のX座標が初期値であることを確認する
- 2個目を非表示にし、1個目が変化しないことを確認する

### Step 3：画像読み込みの統一

#### 作業内容

キャンバスクリック、ドラッグ＆ドロップ、レイヤー追加メニューの画像読み込み処理を共通化する。

対応形式はPNG、JPEG、WebPとする。保存できる形式へ変換してプロジェクトに保持する。

#### 完了条件

- 3つの読み込み経路が共通処理を利用する
- 画像追加時に不要な重複レイヤーを作成しない
- 画像名が他オブジェクト追加で変わらない
- 無効ファイルを通知できる

#### テスト要件

- PNGをクリックで読み込む
- JPEGをドラッグ＆ドロップで読み込む
- WebPをレイヤー追加メニューから読み込む
- 各画像が1レイヤーで表示されることを確認する
- 無効形式でエラー通知を確認する
- ファイル選択後に処理が継続して発火しないことを確認する

### Step 4：空キャンバスとキャンバス枠

#### 作業内容

画像なしで始める機能をプロジェクト状態へ統合する。幅・高さ、枠線の濃さ・太さを保持し、書き出しにも同じ値を使う。

#### 完了条件

- 指定サイズのキャンバス枠が表示される
- 画像なしでも枠が表示される
- 濃さ100%が黒になる
- 枠線がオブジェクトより前面に表示される

#### テスト要件

- 幅800、高さ600の空キャンバスを作成する
- 指定した縦横比と表示が一致することを確認する
- 幅0、負数、空欄では作成できないことを確認する
- 濃さ0%、50%、100%を確認する
- オブジェクトを枠外へ移動し、枠線が最前面であることを確認する

### Step 5：図形オブジェクトの完全対応

#### 作業内容

四角形、円形、三角形へ塗り色、位置、拡大率、回転、透明度、表示状態、名前、削除、レイヤー順を実装する。

#### 完了条件

- 図形を複数追加できる
- 各図形を個別に選択できる
- 図形の座標変更で画像や他の図形が動かない
- 表示・非表示、削除が動作する

#### テスト要件

- 3種類の図形を追加する
- 各図形がキャンバスに表示されることを確認する
- 四角形を移動して画像が動かないことを確認する
- 図形を非表示にして他オブジェクトが残ることを確認する
- 同じ図形を複数追加し、値が独立していることを確認する

### Step 6：テキストオブジェクト

#### 作業内容

テキスト追加、文字列、フォントサイズ、文字色、太字、斜体、位置、拡大率、回転、透明度を実装する。

#### 完了条件

- テキストを追加・編集できる
- テキストがキャンバスへ表示される
- 画像や図形と同じレイヤー操作に対応する

#### テスト要件

- テキストを追加する
- 文字列、サイズ、色を変更する
- 太字と斜体を切り替える
- 移動、回転、透明化、非表示、削除を確認する
- 日本語、長文、空文字を確認する

### Step 7：初期エフェクトのオブジェクト単位管理

#### 作業内容

X座標、Y座標、拡大率、回転、透明度を各オブジェクトの`transform`へ統合する。数値入力と左右ドラッグを同じ更新処理へ接続する。

#### 完了条件

- 選択中オブジェクトだけが変形する
- オブジェクト間で値が共有されない
- 透明度0%が不透明、100%が完全透明になる
- リセットが対象項目だけに作用する
- 不正値を通知できる

#### テスト要件

- 画像のX座標を変更する
- 図形を選択し、図形のX座標が初期値であることを確認する
- 図形のY座標、拡大率、回転を変更する
- 画像の状態が変わらないことを確認する
- 透明度0%、50%、100%を確認する
- 数値入力と行の左右ドラッグを確認する
- 対象行のホバー表示を確認する

### Step 8：追加エフェクトの整理

#### 作業内容

追加エフェクトをオブジェクトごとの配列として管理する。各エフェクトに一意なID、種別、展開状態、固有値、並び順を持たせる。

対象は色調補正、透過とする。

#### 完了条件

- 同じエフェクトを複数追加できる
- 選択中オブジェクトだけに追加される
- オブジェクト切り替えで対象のエフェクトだけが表示される
- 既存の同名エフェクトが勝手に展開されない
- エフェクトを削除できる

#### テスト要件

- 同じエフェクトを2個追加する
- 片方だけ展開する
- さらに同名エフェクトを追加し、既存が展開されないことを確認する
- 他のオブジェクトでエフェクトが表示されないことを確認する
- 削除後に一覧から消えることを確認する

### Step 9：色調補正・透過エフェクト

#### 作業内容

色相、彩度、明度を実装する。透過エフェクトにクロマキー、カラーキー、ルミナンスキー、キーカラー、許容値を実装する。

#### 完了条件

- 色調補正の各値が対象オブジェクトへ反映される
- 透過方式を選択できる
- キーカラーと許容値を設定できる
- 他オブジェクトへ影響しない

#### テスト要件

- 色相、彩度、明度を個別に変更する
- クロマキー、カラーキー、ルミナンスキーを確認する
- 許容値を変更する
- 他オブジェクトの値が変わらないことを確認する

### Step 10：レイヤー順の並べ替え

#### 作業内容

レイヤー一覧をドラッグ＆ドロップで並べ替え、描画順へ反映する。キーボード操作時の代替手段も用意する。

#### 完了条件

- レイヤー行を上下に移動できる
- キャンバス上の前後関係が変わる
- 選択状態が維持される
- 並べ替えをUndo / Redoできる

#### テスト要件

- 3つ以上のオブジェクトを追加する
- レイヤーを上下へ移動する
- 前後関係が変化することを確認する
- ドラッグ中の表示を確認する
- 選択状態が維持されることを確認する
- Undo / Redoで順序を戻す

### Step 11：Undo / Redo

#### 作業内容

プロジェクト状態のスナップショット履歴を実装する。ヘッダーボタンとキーボードショートカットに対応する。

対象は追加、削除、移動、変形、表示切り替え、名前変更、テキスト編集、エフェクト変更、並べ替え、枠線設定とする。

#### 完了条件

- 主要編集をUndoできる
- Undoした操作をRedoできる
- Undo後に新しい操作をするとRedo履歴が消える
- 空履歴でエラーにならない

#### テスト要件

- 追加、削除、座標変更、エフェクト変更をUndo / Redoする
- レイヤー順変更をUndo / Redoする
- Undo後に新しい操作を行い、Redoが消えることを確認する
- Ctrl / Cmd + Z、Ctrl / Cmd + Shift + Zを確認する
- ボタンの無効状態を確認する

### Step 12：ブラウザ自動保存・復元

#### 作業内容

LocalStorageまたはIndexedDBへプロジェクトを自動保存する。保存データにバージョンを付け、画像も復元可能な形式で保持する。

#### 完了条件

- 編集中の状態が自動保存される
- ページ再読み込み後に復元される
- ブラウザ再起動後にも復元される
- 壊れた保存データでも空状態から起動できる
- 保存容量超過時にアプリが停止しない

#### テスト要件

- 画像、図形、テキスト、エフェクト、レイヤー順を変更する
- ページを再読み込みする
- すべての状態が復元されることを確認する
- ブラウザを再起動して画像が復元されることを確認する
- 保存データ破損時の通知と空状態を確認する

### Step 13：画像合成とPNG / JPEG出力

#### 作業内容

HTML Canvasへ背景、レイヤー、エフェクト、枠線を合成し、PNGまたはJPEGとして書き出す。

描画順は以下とする。

1. 透明背景またはJPEG用背景
2. 下位レイヤー
3. 上位レイヤー
4. エフェクト
5. 最前面の枠線

#### 完了条件

- PNGを書き出せる
- JPEGを書き出せる
- 出力サイズがキャンバスサイズと一致する
- 非表示オブジェクトが出力されない
- レイヤー順とエフェクトが反映される
- PNGの透明背景が保持される
- JPEGの透明部分が背景色になる
- プロジェクト名をファイル名に使用する

#### テスト要件

- 800×600のキャンバスを作成する
- 画像、図形、テキストを配置する
- PNGとJPEGを書き出す
- 出力画像の幅・高さを確認する
- 透明部分を確認する
- 非表示レイヤーが出力されないことを確認する
- レイヤー順とキャンバス外の切り落としを確認する

### Step 14：プロジェクト名・ファイルメニュー

#### 作業内容

ヘッダーへプロジェクト名編集と、新規作成、画像読み込み、画像削除、PNG出力、JPEG出力を追加する。

#### 完了条件

- 編集中の新規作成時に確認できる

#### テスト要件

- プロジェクト名を変更する

- 変更後の名前で書き出す
- ファイルメニューを開閉する
- 編集中に新規作成し、確認表示を確認する

### Step 15：アクセシビリティとキーボード操作

#### 作業内容

オブジェクト選択、レイヤー操作、メニュー開閉、エフェクト展開、数値入力、Undo / Redo、書き出しをキーボードから操作できるようにする。

フォームラベル、ARIA属性、フォーカス表示、セマンティックHTMLを整備する。

#### 完了条件

### Step 16：UI・レスポンシブ・エラー状態の仕上げ

## 追加設計：AviUtl風の基本図形

基本図形の詳細な操作・データモデル・描画順・受入テストは、[基本図形の動作設計書](./basic-shape-design.md)に定義する。

この設計は次の実装順で進める。

1. 図形固有プロパティを既存のオブジェクトモデルから分離する
2. 共通図形レンダラーへ塗り・線・縦横比・角の丸みを集約する
3. 図形設定アコーディオンを追加する
4. Undo / Redo、自動保存、書き出しへ図形固有プロパティを接続する
5. 多角形・星形・カスタム図形を拡張する
