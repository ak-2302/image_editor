# 基本図形の動作設計書

## 1. 目的

画像編集アプリへ、AviUtlの図形オブジェクトに近い「図形を選び、外観と変形を数値で調整する」操作を追加する。

対象は、画像編集や簡易デザインを行う制作者とする。図形は背景、枠、マスクの代替、装飾、テキストの背面オブジェクトとして使える独立レイヤーにする。

この設計はAviUtlの操作原則を参考にするが、コードや画面を複製しない。既存アプリの「1オブジェクト選択」「オブジェクトごとのエフェクト」「右側パネル」という構造を優先する。

## 2. 参考にした操作原則

AviUtlの図形オブジェクトでは、背景・円・四角形・三角形・五角形・六角形・星形などの図形種別、サイズ、縦横比、ライン幅を扱う。数値の直接入力と、数値部分を左右にドラッグして変更する操作も使われる。

AviUtl2の公式ドキュメントでは、図形の色、サイズ、ライン幅、角の丸み、アスペクト比を設定できる。設定項目のグループ化や、条件に応じた項目の表示切替も定義されている。

参考資料：

- [AviUtl 設定ダイアログの使い方](https://aviutl.info/setteidaiarogu/)
- [AviUtl2 Lua 図形設定項目](https://docs.aviutl2.jp/lua/)
- [AviUtl 図形パラメータ](https://scrapbox.io/aviutl/%E5%9B%B3%E5%BD%A2)

## 3. 対象範囲

### MVPで対応する図形

- 四角形
- 円形
- 三角形

### 第2段階で追加する図形

- 五角形
- 六角形
- 星形
- 線分
- カスタムSVGまたは白黒PNG図形

最初から図形種別を増やしすぎず、共通設定パネルへ新しい図形を追加できる構造を優先する。

## 4. ユーザー操作

### 4.1 追加

レイヤー欄の「＋」から「図形」を選び、図形種別を選択する。

```text
オブジェクトを追加
├─ 画像
├─ 図形
│  ├─ 四角形
│  ├─ 円形
│  └─ 三角形
└─ テキスト
```

追加した図形は独立レイヤーとして一覧へ追加し、既存オブジェクトの名前・変形値・エフェクトを変更しない。

### 4.2 選択と編集

- キャンバスまたはレイヤー一覧から図形を選択する
- 同時選択は1オブジェクトだけにする
- 選択中の図形だけ右側に図形設定を表示する
- 変形値は既存の初期エフェクトで編集する
- 図形固有値は「図形」アコーディオンで編集する

### 4.3 キャンバス操作

- 図形本体のドラッグ：X座標・Y座標を変更
- ハンドルのドラッグ：拡大率を変更
- 回転ハンドルのドラッグ：回転を変更
- 数値欄以外の行を左右ドラッグ：対象値を変更
- 数値欄のクリック：直接入力
- Shiftを押した左右ドラッグ：微調整モード

キャンバス操作と右側の数値入力は同じ更新関数を使う。

## 5. 図形固有パラメータ

### 5.1 共通パラメータ

| 項目 | 型 | 初期値 | 説明 |
| --- | --- | ---: | --- |
| 図形種別 | union | 四角形 | 四角形・円形・三角形など |
| 色 | string | `#ffffff` | 図形と輪郭に共通して使う色 |
| ライン幅 | number | 0px | ライン幅だけで塗りつぶし／輪郭を判定 |
| 縦横比 | number | 0 | 0は標準比率 |
| 角の丸み | number | 0 | 四角形のみ有効 |
| 反転X | boolean | false | 左右反転 |
| 反転Y | boolean | false | 上下反転 |

### 5.2 図形種別ごとの表示項目

| 図形 | 表示する項目 | 非表示にする項目 |
| --- | --- | --- |
| 四角形 | 色、ライン幅、横幅、縦幅、角の丸み | なし |
| 円形 | 色、ライン幅、横幅、縦幅 | 角の丸み |
| 三角形 | 色、ライン幅、横幅、縦幅 | 角の丸み |
| 五角形以降 | 色、ライン幅、横幅、縦幅、頂点数 | 形状に無関係な項目 |

図形種別を変更しても共通パラメータは保持する。無効になった項目は保存してよいが、表示と描画では無効扱いにする。

## 6. データモデル

```ts
type ShapeKind =
  | "rectangle"
  | "circle"
  | "triangle"
  | "polygon"
  | "star"
  | "line";

type ShapeProperties = {
  kind: ShapeKind;
  color: string;
  lineWidth: number;
  width: number;
  height: number;
  cornerRadius: number;
  vertexCount?: number;
  aspectRatio: number;
  flipX: boolean;
  flipY: boolean;
};

type ShapeLayer = ObjectLayer & {
  type: "shape";
  shape: ShapeProperties;
};
```

既存の`rectangle`・`circle`・`triangle`をすぐに破壊的変更しない。移行時は、現在のレイヤー種別を`shape.kind`へ変換するアダプターを用意し、保存データのバージョンを上げる。

## 7. UI構成

```text
右パネル
├─ オブジェクト
│  └─ レイヤー一覧
└─ 選択中オブジェクトのエフェクト
   ├─ 初期エフェクト
   │  ├─ X座標
   │  ├─ Y座標
   │  ├─ 拡大率
   │  ├─ 回転
   │  └─ 透明度
   └─ 図形
      ├─ 図形種別
      ├─ 色
      ├─ ライン幅
      ├─ 横幅 / 縦幅
      ├─ 縦横比
      └─ 角の丸み
```

図形設定は初期エフェクト内へ含める。アコーディオンの見出しは「四角形」「円形」「三角形」のように図形名だけを表示する。初期エフェクトは「どこに、どの大きさで、どの向きで置くか」、図形設定は「何を、どの外観で描くか」を担当する。

各行は次の構造に統一する。

```text
項目名        数値入力 / 色入力      単位      初期値にリセット
```

色入力はカラーピッカーと16進数入力の両方を用意する。色だけで状態を伝えず、16進値も確認できるようにする。

## 8. 描画仕様

### 8.1 座標系

- 図形の原点は図形の中心
- X / Yはキャンバス中心からの相対座標
- 図形固有の幅・高さは原点を中心に描画
- 回転・拡大率は図形固有サイズへ適用する
- 図形外へのはみ出しは許可する
- 出力時はキャンバス矩形でクリップする

### 8.2 描画順

レイヤー一覧の上から下を前面から背面の順とし、描画時は背面から前面へ反転して処理する。エフェクトはオブジェクト内の一覧順に上から下へ適用する。

### 8.3 線幅

- `lineWidth = 0`：塗りつぶし
- `lineWidth > 0`：指定したピクセル幅の輪郭のみ
- ライン幅に固定の最大値は設けない
- 線は図形の内側へ収める
- ライン幅が図形サイズを超えても、図形の外寸は変化させない
- 円形の線幅変更でドーナツ状の表現を作れる

## 9. 状態変更と履歴

以下を1回の編集操作としてUndo / Redoへ登録する。

- 図形の追加・削除
- 図形種別、色、線幅、縦横比、角の丸みの変更
- 図形の変形
- 表示・非表示、レイヤー順変更

左右ドラッグ中は毎ピクセルで履歴を作らず、ドラッグ開始時の状態を1件だけ記録し、ドラッグ終了時に確定する。

## 10. 実装フェーズ

### Phase A：モデル分離

- `ShapeProperties`を追加
- 既存図形レイヤーからの読み取りアダプターを追加
- 保存データのバージョンを更新

### Phase B：共通描画

- `ShapeRenderer`を図形種別から分離
- 塗り、線、縦横比、角の丸みを共通処理化
- レイヤー順と選択中変形を接続

### Phase C：図形設定UI

- `ShapeSettingsAccordion`を追加
- 数値入力、左右ドラッグ、色入力、リセットを追加
- 図形種別に応じた項目の表示切替を追加

### Phase D：拡張図形

- 多角形の頂点数
- 星形の内外半径
- 線分の始点・終点
- SVG / PNG図形の読み込み

## 11. 受入テスト

- 四角形、円形、三角形を追加できる
- 同じ図形を2個追加し、色・線幅・サイズが共有されない
- 図形の座標変更で他オブジェクトが移動しない
- 塗り色と線色を別々に変更できる
- 線幅0と線幅10を比較できる
- 四角形の角の丸みが円形・三角形に表示されない
- 縦横比を変更して楕円・長方形を作れる
- 図形をキャンバス外へ移動できる
- レイヤー順を変更すると前後関係が変わる
- 非表示図形が画面と出力の両方から消える
- Undo / Redoで図形設定を戻せる
- 再読み込み後に図形設定が復元される
- PNG / JPEG出力へ図形設定が反映される
- キーボードだけで図形追加と設定変更ができる

## 12. 採用しない操作

初期実装では、動画編集向けの時間軸、キーフレーム、再生中のパラメータ変化は扱わない。将来アニメーションを追加する場合は、現在の静的な`EffectInstance`へ時間情報を直接足さず、別のキーフレームモデルとして設計する。
