# AviUtl系エフェクト 要件定義書

## 1. 目的

Image EditorへAviUtlの考え方を参考にした画像処理エフェクトを追加する。対象は画像・図形・テキストの全オブジェクトとし、オブジェクト単位で独立したエフェクトを保持する。

完全なAviUtl互換ではなく、既存のアコーディオンUI、数値入力、左右ドラッグ操作、オブジェクト単位の保存・復元を優先する。

## 2. 対象エフェクト

| エフェクト | 主な設定 |
| --- | --- |
| 単色化 | 色、強度 |
| グラデーション | 開始色、終了色、角度、強度 |
| グロー | 色、強度、半径、透明度 |
| ぼかし | 半径(px) |
| モザイク | ブロックサイズ(px)、強度 |
| クリッピング | 上・下・左・右(px) |
| 斜めクリッピング | 方向、角度、位置、ぼかし、反転 |
| マスク | 円・四角・楕円、位置、幅、高さ、ぼかし、反転 |
| シャドー | 色、濃さ、距離、角度、ぼかし |
| 縁取り | 色、太さ(px)、濃さ |
| 画像ループ | X/Y繰り返し、オフセット、ミラー、透明度 |

## 3. 共通仕様

- エフェクトはオブジェクトごとに独立して保持する。
- 同じエフェクトを複数追加できる。
- 一覧の上から下へ順番に適用する。
- 既存のアコーディオンと左右ドラッグ対応の入力行を再利用する。
- 画像、図形、テキストすべてを対象とする。
- 既存プロジェクトの不足値は各エフェクトの初期値で補完する。
- Fabric.js表示とPNG/JPEG書き出しで同じ処理を使用する。
- Undo/Redo、自動保存、復元の対象にする。

## 4. 初期値と入力

初期値は効果が目立たない自然な値とする。px項目は0以上、強度・濃さ・透明度は0〜100%を基本とする。色はカラーコード入力とカラーピッカーに対応する。値の上限を固定しない項目はブラウザ性能の範囲で処理する。

## 5. 描画仕様

- 色系・ぼかし系はFabric.jsフィルタを優先する。
- マスク、クリッピング、縁取り、シャドーはアルファマスクまたはSVG合成を使用する。
- グラデーション、モザイク、画像ループは必要に応じてオフスクリーンCanvasを使用する。
- エフェクト順は一覧順を維持する。
- キャンバス外の描画は表示・書き出し範囲外へ出さない。

## 6. 受入条件

- 11種類すべてを追加・編集・削除・並べ替えできる。
- オブジェクト間で値が共有されない。
- 画面表示と書き出し結果が一致する。
- 保存・復元、Undo/Redoが動作する。
- PNG/JPEG出力へ反映される。
- `npm run lint`、`npm run build`が成功する。
- Chromeのコンソールにエラーがない。
