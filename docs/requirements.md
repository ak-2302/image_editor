# Image Editor 要件定義書

## 1. 文書情報

| 項目 | 内容 |
| --- | --- |
| プロダクト名 | Image Editor |
| 文書種別 | 要件定義書 |
| 対象 | PC向け画像編集アプリ |
| UI言語 | 日本語 |
| 主要ブラウザ | 最新版Chrome |
| ステータス | MVP要件 |

## 2. 製品概要

Image Editorは、画像や図形、テキストをキャンバス上に配置し、オブジェクトごとにエフェクトや変形を適用して画像を書き出すブラウザベースの画像編集アプリである。

主な利用者は、画像加工や簡易デザイン制作を行う開発者・制作者とする。サーバーに依存せず、ブラウザ上で編集、保存、復元、書き出しまで完結できることを目標とする。

## 3. 目的と成功条件

### 3.1 目的

- 画像編集のための確認しやすいPC向け操作画面を提供する
- オブジェクト単位で独立した編集状態を管理する
- レイヤーとエフェクトを整理して操作できるようにする
- 編集結果を画像ファイルとして書き出せるようにする

### 3.2 成功条件

- 画像を読み込み、キャンバス上で確認できる
- 画像、図形、テキストを複数配置できる
- 選択中のオブジェクトだけを編集できる
- オブジェクト間でパラメータが共有されない
- レイヤー順、表示状態、エフェクトを管理できる
- PNGまたはJPEGとしてキャンバスサイズで書き出せる
- ブラウザを再起動しても編集中のプロジェクトを復元できる

## 4. 対象範囲

### 4.1 MVPに含める機能

- 画像の読み込み
- 空キャンバスの作成
- 画像、図形、テキストの追加
- オブジェクトの選択、移動、変形、削除
- レイヤーの表示状態、名前、順序の管理
- オブジェクト単位の初期エフェクトと追加エフェクト
- Undo / Redo
- ブラウザ内への自動保存と復元
- PNG / JPEG書き出し
- 枠線の設定

### 4.2 MVPに含めない機能

- 複数オブジェクトの同時選択
- クラウド保存
- ログイン、ユーザー管理、共同編集
- モバイル専用UI
- 動画・アニメーション編集
- ブラシ、消しゴム、マスク、複雑な画像合成

## 5. 利用環境

- 最新版Chromeを動作保証対象とする
- PC画面を主要対象とする
- React、TypeScript、Viteを使用する
- サーバーなしで基本編集を完結する
- 編集状態はブラウザ内に保存する
- UIおよびユーザー向けメッセージは日本語とする

## 6. 用語定義

| 用語 | 定義 |
| --- | --- |
| キャンバス | 編集対象を配置する出力領域 |
| オブジェクト | 画像、図形、テキストなどキャンバス上に配置する要素 |
| レイヤー | オブジェクトの表示状態、名前、順序を管理する単位 |
| 初期エフェクト | 全オブジェクトが持つ位置・変形・透明度の設定 |
| 追加エフェクト | 明るさ、色調補正など、初期エフェクトとは別に追加する処理 |
| 選択中オブジェクト | 現在編集対象になっている1つのオブジェクト |
| プロジェクト | キャンバス、オブジェクト、エフェクト、設定をまとめた編集状態 |

## 7. 画面要件

### 7.1 全体レイアウト

- ヘッダーは最小限の構成とする
- ヘッダーにファイル、設定、Undo、Redo、書き出しを配置する
- 左側にキャンバスを配置する
- 右側にレイヤーとエフェクトのパネルを配置する
- レイヤー領域とエフェクト領域を境界線で分割する
- 画面全体の縦スクロールを発生させない
- 右側パネル内は、項目が多い場合に内部スクロールできる
- メニュー、ポップアップ、追加メニューは外側クリックで閉じる

### 7.2 キャンバス領域

- 空状態では、クリックまたはドラッグ＆ドロップで画像を読み込めることを案内する
- 画像なしで始める操作を提供する
- キャンバス枠を表示する
- キャンバス枠はオブジェクトより前面に表示する
- オブジェクトがキャンバス外にはみ出しても表示できる
- キャンバス外のオブジェクトは書き出し時に出力範囲外を切り落とす

### 7.3 レイヤー領域

- 右側上部にオブジェクト一覧を表示する
- 一覧には複数オブジェクトを同時に確認できる細いリスト形式を用いる
- 各行に表示・非表示、名前変更、削除の操作を配置する
- 追加ボタンから画像、図形、テキストを選択できる
- 一覧の順序を描画順に反映する
- 行をドラッグして前後関係を変更できる
- 選択中の行を視覚的に区別する

### 7.4 エフェクト領域

- 選択中オブジェクトのエフェクトだけを表示する
- 初期エフェクトを上部に表示する
- 追加エフェクトを初期エフェクトの下に表示する
- エフェクト追加ボタンを右下に配置する
- 各エフェクトはアコーディオン形式で表示する
- 各エフェクトに3点メニューを配置する
- 3点メニューからエフェクトを削除できる
- エフェクトの並べ替え中は移動アニメーションを表示する

## 8. キャンバス要件

### 8.1 画像の読み込み

- クリックによるファイル選択に対応する
- ドラッグ＆ドロップに対応する
- 対応形式はPNG、JPEG、WebPとする
- 不正な形式のファイルは読み込まず、簡易通知で理由を表示する
- 画像読み込み後は、画像がキャンバスとレイヤー一覧へ反映される
- 同じ画像を読み込んだ結果として不要な重複レイヤーを作成しない
- 画像サイズに上限は設けず、ブラウザ性能の範囲で処理する

### 8.2 空キャンバス

- 画像なしで始める操作を提供する
- 幅と高さを数値入力できる
- 幅と高さは1以上の整数とする
- 指定した幅・高さをキャンバスサイズとして保持する
- 指定したキャンバスサイズを出力サイズに使用する

### 8.3 枠線

- 枠線の濃さを設定できる
- 枠線の太さを設定できる
- 濃さは0〜100%で指定する
- 濃さ100%は完全な黒（`#000000`）として描画する
- 枠線は画像、図形、テキストより前面に表示する
- 枠線設定はUndo / Redoの対象とする

## 9. オブジェクト要件

### 9.1 対応する種別

- 画像
- 四角形
- 円形
- 三角形
- テキスト

### 9.2 共通データ

各オブジェクトは、少なくとも以下を保持する。

- 一意なID
- オブジェクト種別
- 表示名
- 表示・非表示状態
- X座標
- Y座標
- 拡大率
- 回転角度
- 透明度
- オブジェクト固有のエフェクト一覧

画像オブジェクトは画像データまたは復元可能な画像参照を保持する。テキストオブジェクトは文字列、フォントサイズ、文字色、太字、斜体を保持する。

### 9.3 選択

- 同時に選択できるオブジェクトは1つだけとする
- レイヤー一覧のクリックで選択できる
- キャンバス上のオブジェクトクリックでも選択できる
- 選択したオブジェクトの種類を初期エフェクト名へ反映する
- オブジェクト切り替え時に、対象オブジェクトの状態を復元する
- 他のオブジェクトの位置、エフェクト、表示状態を変更しない

### 9.4 操作

- キャンバス上のドラッグで位置を変更できる
- キャンバス上で拡大・縮小できる
- キャンバス上で回転できる
- 右側パネルの数値入力で位置、拡大率、回転を変更できる
- 数値入力欄以外の値の行を左右ドラッグして値を変更できる
- 変更対象の行はホバー時に色を変える
- オブジェクト名を変更できる
- オブジェクトを表示・非表示にできる
- オブジェクトを削除できる

## 10. レイヤー要件

- レイヤー一覧はオブジェクトの追加順または現在の並び順を保持する
- レイヤー行のドラッグで順序を変更できる
- 並び順の変更をキャンバスの前後関係へ反映する
- 表示・非表示の変更をキャンバスへ即時反映する
- レイヤー削除後は、削除したオブジェクトをキャンバスに表示しない
- 選択中のオブジェクトを削除した場合は、残っているオブジェクトまたは未選択状態へ移行する
- レイヤー追加時に、既存オブジェクトの名前を意図せず変更しない

## 11. 初期エフェクト要件

全オブジェクトは、以下の初期エフェクトを独立して保持する。

| 項目 | 初期値 | 単位・ルール |
| --- | ---: | --- |
| X座標 | 0 | px。範囲制限なし |
| Y座標 | 0 | px。範囲制限なし |
| 拡大率 | 100 | %。範囲制限なし |
| 回転 | 0 | 度。範囲制限なし |
| 透明度 | 0 | %。0は不透明、100は完全透明 |

- 各項目を数値入力できる
- 数値、単位、リセットボタンを1行に表示する
- 初期値へリセットできる
- 透明度のみ0〜100の範囲に制限する
- 空欄、非数値、不正な値は簡易通知で知らせる
- 初期エフェクトの変更をUndo / Redoの対象とする

## 12. 追加エフェクト要件

### 12.1 エフェクト種別

- 色調補正
- 透過

透過エフェクトは、以下の方式を設定できる。

- クロマキー
- カラーキー
- ルミナンスキー

### 12.2 適用ルール

- エフェクトはオブジェクト単位で保持する
- 同じエフェクトを複数追加できる
- 一覧順に上から下へ適用する
- エフェクトの値を別オブジェクトと共有しない
- 選択オブジェクトを変更しても、過去のオブジェクトのエフェクト表示状態を勝手に変更しない

### 12.3 UI操作

- エフェクト追加ボタンは右下に配置する
- 追加メニューは外側クリックで閉じる
- 追加したエフェクトだけを展開する
- 同名エフェクトの追加時に、過去の同名エフェクトを展開しない
- 初期エフェクト以外はアコーディオン部分をドラッグして上下移動できる
- 移動中の対象が分かるように表示する
- 移動完了時に短いアニメーションを表示する
- 3点メニューから削除できる
- 削除後に対象エフェクトを一覧から取り除く

## 13. テキスト要件

- テキストオブジェクトを追加できる
- 文字列を入力、変更できる
- フォントサイズを変更できる
- 文字色を変更できる
- 太字を設定できる
- 斜体を設定できる
- 画像や図形と同じ位置、拡大率、回転、透明度を設定できる
- テキストも表示・非表示、名前変更、削除、並べ替えに対応する

## 14. 書き出し要件

- PNGまたはJPEGを選択して書き出せる
- 出力サイズはキャンバスの幅・高さと一致させる
- 非表示オブジェクトは出力しない
- レイヤー順を反映して合成する
- エフェクト適用後の見た目を出力する
- キャンバス外の部分は出力範囲から切り落とす
- PNGでは透明背景を保持する
- JPEGでは透明部分を適切な背景色へ変換する
- プロジェクト名をファイル名に使用する
- プロジェクト名は初期値から変更できる
- 書き出し失敗時は簡易通知を表示する

## 15. 保存・復元要件

### 15.1 保存方式

- ブラウザ内へ自動保存する
- 次回起動時に前回の編集状態を復元する
- サーバーへの送信は行わない
- 保存データにはバージョン情報を持たせる

### 15.2 保存対象

- プロジェクト名
- キャンバスサイズ
- オブジェクト一覧
- オブジェクト種別
- レイヤー順
- 表示・非表示状態
- オブジェクト名
- 画像データまたは復元可能な画像情報
- テキスト内容と文字設定
- 位置、拡大率、回転、透明度
- オブジェクトごとのエフェクト一覧と値
- 枠線の濃さと太さ

### 15.3 容量超過

- 保存容量を超えた場合は古い履歴から削除する
- 現在の編集状態の保存を優先する
- 保存できない場合は簡易通知を表示する
- 復元できないデータは画面を壊さず、空状態から開始できる

## 16. Undo / Redo要件

以下を履歴対象とする。

- オブジェクトの追加
- オブジェクトの削除
- オブジェクトの移動
- 拡大・縮小
- 回転
- 表示・非表示切り替え
- 名前変更
- テキスト内容・文字設定の変更
- エフェクトの追加、削除、変更
- エフェクトの並べ替え
- レイヤー順の変更
- 枠線設定の変更

Undo / Redoはヘッダーのボタンとキーボードショートカットから実行できる。Undo後に新しい編集を行った場合、それ以降のRedo履歴は破棄する。

## 17. 非機能要件

### 17.1 操作性

- 主要操作は画面内で完結する
- UI操作中に意図しないページスクロールを発生させない
- オブジェクト数が増えてもレイヤー一覧で確認できる
- 画像読み込み後に画面表示を確実に更新する
- メニューやアコーディオンの状態が意図せず他の項目へ伝播しない

### 17.2 アクセシビリティ

- セマンティックHTMLを使用する
- すべての入力にラベルを付ける
- アイコンだけのボタンに`aria-label`を付ける
- キーボードで主要操作を実行できる
- フォーカス状態を視覚的に表示する
- 色だけで表示状態や選択状態を伝えない
- 画像に適切な代替テキストを付ける
- 動きは必要最小限とし、低減設定を尊重する

### 17.3 品質

- コンソールエラーを発生させない
- 不正なファイル形式を安全に処理する
- 操作中に大きなちらつきを発生させない
- `npm run lint` が成功する
- `npm run build` が成功する

## 18. 受入条件

### 18.1 基本操作

- 画像をクリックで読み込める
- 画像をドラッグ＆ドロップで読み込める
- PNG、JPEG、WebPを読み込める
- 空キャンバスを指定サイズで作成できる
- 画像、四角形、円形、三角形、テキストを追加できる

### 18.2 オブジェクト・レイヤー

- 同時に1つだけ選択できる
- 選択中オブジェクトをキャンバスとレイヤー一覧で確認できる
- 表示・非表示が動作する
- 名前変更が動作する
- 削除が動作する
- レイヤー順の変更が描画順へ反映される
- 図形の座標変更で画像が移動しない

### 18.3 エフェクト

- 選択中オブジェクトのエフェクトだけが表示される
- オブジェクト間でエフェクト値が共有されない
- 初期エフェクトの値を入力できる
- 行のドラッグで数値を変更できる
- エフェクトの追加、複数追加、削除、並べ替えが動作する
- 並べ替え時に移動アニメーションが表示される
- 透明度0%が不透明、100%が完全透明になる

### 18.4 保存・出力

- 編集状態が自動保存される
- ブラウザ再起動後に編集状態を復元できる
- Undo / Redoが主要操作で動作する
- PNGを書き出せる
- JPEGを書き出せる
- 出力画像のサイズがキャンバスサイズと一致する
- 非表示オブジェクトが出力されない
- PNGの透明背景が保持される

### 18.5 品質確認

- 最新版Chromeで画面が表示される
- 初期画面が空白にならない
- フレームワークのエラー画面が表示されない
- ブラウザコンソールにアプリエラーがない
- デスクトップ幅でレイアウトが崩れない
- 狭い幅でも主要操作が確認できる
- キーボードフォーカスが確認できる
- `npm run lint` が成功する
- `npm run build` が成功する
